## 3. 物种条目

### 1. 老鼠 · 切达
- **罪行**：奶酪盗窃罪 —— 偷走全镇奶酪，要求自己是奶酪世界的唯一主宰。
- **编号 #1001**：万物归一，少一不行；全世界奶酪都是我的，少一块都不行，这叫 1001% 独占。
- **物种语料方向（ANIM-15 物种通用池参考）**：奶酪 / 独占 / 暴走（与个体「独占口吻」一致）。

### 2. 大黄狗 · 保罗
- **罪行**：舔狗罪 —— 表忠心、自愿降薪，最终成裁员参考名单"留观"。
- **编号 #1314**：一生饲主（谐音"一生之主"）。
- **物种语料方向（ANIM-15 物种通用池参考）**：忠诚 / 讨好 / 「汪!」（与个体「忠诚狗语」一致）。

### 3. 奶牛猫 · 普茜
- **罪行**：公平嘲讽罪 —— 规则对它自动失效，是对"公平"最优雅的嘲讽。
- **编号 #2333**：嘲笑一切规则，哈哈哈哈（老钱笑）。
- **物种语料方向（ANIM-15 物种通用池参考）**：松弛 / 老钱 / 拒绝死板规则（与个体「老钱嘲讽」一致）。

### 4. 狐狸 · 乔登
- **罪行**：人设诈骗罪 —— 嘴上功夫、精英人设，爱慕虚荣被举报入狱。
- **编号 #1998**：致敬华尔街之狼崩盘之年，装逼神话终落幕。
- **物种语料方向（ANIM-15 物种通用池参考）**：财经 / 投资 / 品味焦虑（与个体「精英腔」一致）。

### 5. 兔子 · 瑞克
