# 动物监狱 · Demo 交互原型 + UI 文案 Spec（前 10 页）

版本：v0.1 低保真线框（黑白灰，重点引导=橙色）
主题：复古美式 / 幽默诙谐 / 典狱长经营
用途：先跑通交互，不做最终精修

## 全局约定
- 低保真：黑白灰（#111 文字、#eee 底、#ccc 边框、#888 次要），重点引导一律橙色 #ff9f1c。
- 顶栏标题用「动物监狱」系导航，返回按钮保留。
- 底部 TabBar 4 个：办公室 / 牢房 / 动物镇 / 我的。
- 按钮主操作=深灰填�质，次操作=描边；引导强调=橙色填充。
- 文案口吻：典狱长口吻 + 美式冷幽默，诙谐讽刺，不软萌。

## TabBar（4 页）

### 1) 办公室（典狱长办公室）· tab
- 用途：已绑定小动物总览 + 经营概览。
- 线框：
  - 顶部：监狱评分条（数字 + 外显等级徽章）。
  - 中段：小动物横向卡片列表（头像 + 名称 + 满意度条）。
  - 底部：快捷入口「去放风」「去喂食」。
- 橙色引导：满意度最高那只旁点亮「它今天状态不错」；无动物时「去绑定你的第一位囚犯」。
- 文案：
  - 副标题：全员点名！今天谁最听话？
  - 空状态：监狱空荡荡，先绑一只小动物进来撑场面。
  - 评分标签：监狱经营评分 / 外显等级。
  - 快捷按钮：去喂食 / 去放风 / 查记录。

### 2) 牢房（我的小动物）· tab
- 用途：进入每只动物的牢房互动。
- 线框：纵向列表，每项=动物缩略 + 名称 + 满意度条 + 今日剩余次数角标。
- 橙色引导：某只「今日还没喂」点亮「该喂饭了」。
- 文案：
  - 标题：牢房点名册。
  - 空态：尚未收押任何囚犯。
  - 剩余角标：今日可互动 喂2/放1/玩3。

### 3) 动物镇（社交）· tab
- 用途：发布/浏览成就事件、点赞。
- 线框：信息流卡片（发布者 + 内容 + 点赞）+ 顶部「发布」按钮。
- 橙色引导：首条「发布你的第一条监狱动态」。
- 文案：
  - 标题：动物镇街坊。
  - 发布按钮：广播出去。
  - 空态：镇上还没人唠嗑，你来开个头。
  - 点赞：给个赞。

### 4) 我的（账号/设置）· tab
- 用途：账号、等级、设置，后续扩展。
- 线框：列表项（等级/账号/提醒/隐私/帮助）。
- 文案：
  - 标题：典狱长办公室 · 我的。
  - 等级项：外显等级 Lv.X。
  - 设置项：推送提醒 / 隐私协议 / 帮助与反馈。

## 二级页面

### 5) 欢迎（典狱长手册）· 首次绑定引导
- 用途：首次绑定后的引导，介绍玩法。
- 线框：手册卡片（图文）+ 「开始看管」按钮。
- 橙色引导：核心循环一句话高亮「照顾→好感→评分→等级」。
- 文案：
  - 主标题：欢迎上任，新典狱长。
  - 副句：这里由你说了算——前提是别让囚犯饿着。
  - 循环说明：喂食/放风/陪玩 → 提升好感 → 累积经营评分 → 提升外显等级。
  - 按钮：开始看管。

### 6) 绑定（NFC/邀请码）
- 用途：绑定小动物（NFC 触碰 / 邀请码）。
- 线框：区域一=NFC 触碰等待动画；区域二=邀请码输入 + 提交。
- 橙色引导：NFC 不可用时「别急，输邀请码也能进来」。
- 文案：
  - 标题：收押一只新囚犯。
  - NFC 提示：拿起手办贴一下手机（仅支持安卓/鸿蒙）。
  - 邀请码占位：输入囚犯编号。
  - 提交：登记入狱。
  - 成功：恭喜收押，「名字」已被关进牢房。

### 7) 隐私
- 用途：登录/绑定前同意协议。
- 线框：协议正文摘要 + 同意/拒绝按钮。
- 文案：
  - 标题：隐私与用户协议。
  - 摘要：我们收集你的微信身份用于绑定与同步，不做他用。
  - 按钮：同意并继续 / 不同意。

### 8) 牢房详情（喂食/放风/陪玩）· 核心互动
- 用途：单只动物互动。
- 线框：
  - 顶部：动物大头像 + 名称 + 满意度条。
  - 中部：三个互动按钮（喂食 / 放风 / 陪玩），分别带剩余次数。
  - 底部：互动结果卡（Δ好感 + 语料气泡 + 得分）。
- 橙色引导：非时段按钮变灰并提示；当日首次可互动高亮。
- 文案：
  - 标题：牢房 1024 · 「卷王」瑞克。
  - 按钮：喂食 / 放风 / 陪玩。
  - 时段提示：现在不是饭点，等等再喂（喂食仅限餐点）。
  - 结果卡：好感 +6；得分 +5。
  - 语料气泡：角色口吻（如瑞克：「打卡了，领导。」）。

### 9) 食堂（定时发餐）
- 用途：时段领取餐食喂食。
- 线框：今日餐次时间轴 + 领取按钮。
- 橙色引导：当前餐次可领取高亮「现在就领」。
- 文案：
  - 标题：监狱食堂。
  - 餐次：早餐/午餐/晚餐（时段）。
  - 按钮：领取本餐。
  - 已领：本餐已发放。

### 10) 囚犯卡片（角色资料卡）
- 用途：展示角色资料（编号/介绍/编号寓意/生日星座/MBTI）。
- 线框：竖版卡片，头像 + 信息字段。
- 橙色引导：囚犯编号置顶高亮。
- 文案按角色资料表（如「奶酪暴君·切达」，编号 #1001「万物归一，1001% 独占」）。
